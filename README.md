### Примеры кода
Пример реализации интерактивной анкеты студента с расчётом возраста и форматированием вывода:

```csharp
using System;
using System.Globalization;

Console.Write("Введите ваше имя: ");
string name = Console.ReadLine();

Console.Write("Введите ваш год рождения: ");
int birthYear = int.Parse(Console.ReadLine());

Console.Write("Введите ваш средний балл (например, 4.5): ");
string gpaInput = Console.ReadLine().Replace(',', '.');
double gpa = double.Parse(gpaInput, CultureInfo.InvariantCulture);

int currentYear = 2026;
int age = currentYear - birthYear;
string status = gpa >= 4.5 ? "Отличник" : "Хорошист";

Console.WriteLine(\$"Имя: {name} | Возраст: {age} лет | Статус: {status}");
```

### Ответы на вопросы

#### 1. Чем `Console.Write()` отличается от `Console.WriteLine()`?
* `Console.Write()` выводит переданный текст в консоль, оставляя курсор на той же строке. Следующий вывод продолжится сразу за этим текстом.
* `Console.WriteLine()` выводит текст и автоматически осуществляет переход курсора на новую строку.

#### 2. Что произойдёт, если попытаться присвоить переменной типа `int` значение `3.14`?
Произойдёт ошибка компиляции на этапе сборки проекта. Так как C# - язык со статической строгой типизацией, компилятор запрещает неявное приведение типа `double` к типу `int` без потери точности.

#### 3. Почему `10 / 3` в C# даёт `3`, а не `3.333...`? Как получить дробный результат?
В C# операция деления над двумя целыми числами (`int / int`) всегда выполняется как целочисленное деление, отбрасывая дробную часть. Чтобы получить точный дробный результат, необходимо хотя бы один из операндов явно или неявно привести к типу с плавающей точкой:
```csharp
double result1 = 10.0 / 3;
double result2 = (double)10 / 3;
```

#### 4. Что означает `var` в C#? Чем он отличается от динамической типизации в Python?
Ключевое слово `var` включает автоматический вывод типа компилятором на основе присваиваемого значения. 
* **Отличие от Python:** в C# тип переменной определяется строго **один раз** при компиляции и больше не может быть изменён. В Python типизация динамическая, поэтому переменная может свободно менять свой тип в процессе выполнения кода.

#### 5. На каких крупных проектах или компаниях используется C# и .NET?
* **Stack Overflow** - одна из крупнейших платформ вопросов и ответов для программистов в мире, полностью построенная на стеке .NET.
* **Microsoft** - использует C# для разработки внутренних сервисов, игровой экосистемы Xbox, а также операционной системы Windows.
* **Unity Technologies** - игровой движок Unity использует C# в качестве основного языка программирования для написания скриптов и логики игр.
